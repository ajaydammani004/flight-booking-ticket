# AETHERIA SKYWAYS — Luxury Flight Ticket Booking Web App

An ultra-premium, aesthetic, and modern flight ticket booking web application crafted with a midnight velvet and champagne gold palette, fluid micro-interactions, responsive cabin selection, interactive aircraft seat map, and luxury printable/downloadable boarding passes.

---

## 🌟 Key Features

1. **Intelligent Flight Discovery (From & Destination)**
   - Smart autocomplete for top international & domestic airport hubs (BOM, DEL, DXB, LHR, JFK, SIN, HND, CDG, FRA, ZRH, etc.).
   - Airport code chip visualizer and instant swap route button (180° rotation animation).
   - Dynamic travel dates with auto-validation and trip types (One Way, Round Trip, Multi-City VIP).
   - Quick one-click popular journeys (Mumbai ⇄ Dubai, Delhi ⇄ London, New York ⇄ Paris, etc.).

2. **Available Flights Feed & Sorting**
   - High-fidelity flight cards featuring leading global luxury airlines (Emirates, Qatar Airways, Singapore Airlines, Lufthansa, British Airways, Air France).
   - Detailed departure, arrival, flight duration, aircraft type (Boeing 777-300ER, Airbus A380-800, A350-1000), and non-stop / layover tracking.
   - Live sorting by **Cheapest**, **Fastest**, and **Earliest Departure**.
   - Flight filter modal for non-stop direct flights vs stops and airline preferences.

3. **4 Distinct Cabin Class Tiers & Upgrades**
   - **Economy Standard**: Ergonomic seating, 23kg baggage, hot meals.
   - **Premium Economy**: +7" extra legroom, dedicated check-in, 2x 23kg bags, priority boarding.
   - **Business Class Suite**: 180° fully lie-flat bed pod, Michelin-inspired dining, luxury lounge access, Acqua di Parma amenity kit.
   - **First Class Imperial**: Enclosed private suite with sliding doors, vintage Dom Pérignon & caviar service, private chauffeur drive, and shower spa.

4. **Interactive Airplane Fuselage & Seat Selection**
   - Live visual cabin floor plan featuring cockpit marker, window, middle, and aisle seats.
   - Click to choose seats with real-time audio chime and visual gold glow indicator.
   - Dynamic fare calculation updating base fare, airport taxes, carbon offset, and seat reservation in real time.

5. **Traveler Identity & Contact Form**
   - Passenger title, Full legal name as per passport, mobile number with international country dial code picker (`+91`, `+1`, `+44`, `+971`, `+65`, `+33`).
   - Email address for automated ticket dispatch.
   - Passport/National ID number and Date of Birth validation.
   - In-flight gourmet dining preference selector (Chef's Signature, Asian Vegetarian/Jain, Halal, Gluten-Free, Kosher).
   - Frequent Flyer loyalty program input.

6. **Luxury Boarding Pass & Confirmation**
   - PNR & Booking reference generator (e.g. `AETH-98214`).
   - Authentic digital boarding pass with route trajectory line, airline stub, vector QR code, and barcode strip.
   - Multi-color celebration confetti explosion upon booking completion.
   - Dedicated **Print Boarding Pass** button (with high-res clean black-and-white `@media print` layout).
   - **Save Digital Ticket** button (HTML/E-Ticket file export).

7. **Multi-Currency Support**
   - Instant currency switcher in the navbar: **INR (₹)**, **USD ($)**, **EUR (€)**, **GBP (£)**, **AED (د.إ)**, **SGD (S$)**.

## 🚀 How to Run

No installations, build tools, or node/python required! Simply open the project in any web browser:

1. Double click [`index.html`](file:///c:/flight%20booking%20tickt/index.html) in Windows File Explorer.
2. Or in PowerShell:
   ```powershell
   Start-Process index.html
   ```

## 🎨 Design Philosophy
- **Colors**: Deep Midnight Obsidian (`#060911`, `#0B0F19`), Brushed Champagne Gold (`#D4AF37`, `#E5C07B`), Emerald green and subtle amethyst accents.
- **Typography**: Google Fonts *Cinzel* (Hero editorial luxury serif), *Plus Jakarta Sans* (Sleek modern UI sans), and *Space Grotesk* (Precision aviation data).
- **Glassmorphism**: 20px frosted backdrop filters, soft radial ambient light orbs, and subtle night sky starfield overlays.
